一、本章知识框架

二、1.1 数值分析的对象与任务

1. 对象

数值分析是研究用计算机求解数学问题的数值方法。

它研究的是：

  • 如何把数学问题转化为计算机可计算的算法
  • 如何保证计算结果足够准确
  • 如何提高计算效率

2. 常见问题类型

  • 非线性方程求根
  • 线性方程组求解
  • 插值与拟合
  • 数值积分与数值微分
  • 常微分方程初值问题
  • 矩阵特征值问题

3. 数值分析的任务

4. 核心思想

思想 说明
近似代替 用有限过程近似无限过程
离散化 把连续问题变成离散问题
递推化 用递推公式减少计算量
迭代化 用迭代逼近精确解

4. 舍入误差累积

单次舍入误差很小，但大量运算后误差可能累积放大。

影响因素：

  • 运算次数
  • 算法结构
  • 问题本身的条件数

5. 算法的数值稳定性

定义

一个算法如果对初始误差和舍入误差不敏感，计算结果能保持可靠，则称该算法是数值稳定的。

如果误差在计算过程中被不断放大，则称算法不稳定。

  • 看是否除以很小的数

6. 避免不稳定的常用技巧

  • 避免两个相近数相减
  • 避免除以绝对值很小的数
  • 减少运算次数
  • 使用稳定的递推方向
  • 使用高精度数据类型
  • 对公式做等价变形

五、主要考点总结

1. 必背概念

概念 关键点
截断误差 方法本身近似引起
舍入误差 浮点数存储和运算引起
绝对误差 e = x - x*
相对误差 er = e / x
有效数字 与绝对误差限有关
条件数 衡量问题敏感性
机器精度 浮点数表示精度
数值稳定性 误差是否被放大

2. 常考题型

  • 判断误差类型
  • 计算绝对误差限和相对误差限
  • 判断有效数字位数
  • 分析误差传播
  • 判断算法是否稳定
  • 给出避免误差扩大的算法改进

3. 高频考点

  • 用泰勒展开说明截断误差
  • 浮点数舍入误差估计
  • 递推公式稳定性判断
  • 相近数相减的危害
  • 条件数与病态问题

六、易错提醒

  1. 相对误差分母有时用 x，有时用 x*，题目中要看清。
  2. 有效数字位数不是看小数点后有几位。
  3. 截断误差和舍入误差不能混为一谈。
  4. 算法稳定不等于结果绝对精确，只是误差不被严重放大。
  5. 条件数大是问题本身病态，不是算法造成的。
  6. 避免相近数相减，可以通过有理化、泰勒展开等方法改造公式。

七、记忆口诀

八、本章重点一句话

数值分析就是用近似方法求解数学问题，同时研究误差如何产生、如何度量、如何传播，以及如何设计数值稳定的算法。
