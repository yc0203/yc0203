## 一、整体方案

```text
本地写 Markdown
      ↓
Hexo 编译成静态网页
      ↓
推送到 GitHub
      ↓
GitHub Pages 免费托管
```

### 各部分作用

| 组件 | 作用 |
|---|---|
| Node.js | 运行 Hexo 的 JavaScript 环境 |
| npm | Node.js 自带的包管理器，用来安装 Hexo 和插件 |
| Hexo | 静态博客生成器，把 Markdown 编译成 HTML/CSS/JS |
| Butterfly | Hexo 主题，负责博客外观 |
| Git | 本地版本控制工具，用来把文件上传到 GitHub |
| GitHub | 存放代码和网页的远程网站 |
| GitHub Pages | GitHub 提供的免费静态网页托管服务 |

> 简单理解：Git 是本地软件，GitHub 是网页服务。Git 负责上传，GitHub 负责托管。

## 二、准备工作

### 1. 安装 Node.js

官网下载 LTS 版本：

```text
https://nodejs.org
```

安装完成后验证：

```powershell
node -v
npm -v
```

能看到版本号说明安装成功。

### 2. 安装 Git

官网下载：

```text
https://git-scm.com
```

验证：

```powershell
git --version
```

> 注意：是 `git --version`，不是 `git -v`。

### 3. 全局安装 Hexo

```powershell
npm install -g hexo-cli
```

验证：

```powershell
hexo version
```

如果提示权限不够，Windows 可以用管理员身份打开 PowerShell。

---

## 三、初始化博客项目

### 1. 创建项目目录

不要直接在盘符根目录初始化项目，建议先建一个文件夹：

```powershell
E:
mkdir HexoBlog
cd HexoBlog
```

### 2. 初始化 Hexo

```powershell
hexo init myblog
```

这条命令会生成一个名叫 `myblog` 的博客项目。

### 3. 进入项目

```powershell
cd myblog
```

### 4. 安装依赖

```powershell
npm install
```

如果下载超时，可以使用国内镜像：

```powershell
npm config set registry https://registry.npmmirror.com
npm install
```

### 5. 本地预览

```powershell
hexo server
```

浏览器打开：

```text
http://localhost:4000
```

能看到默认博客，说明 Hexo 安装成功。

---

## 四、安装 Butterfly 主题

在博客根目录执行：

```powershell
npm install hexo-theme-butterfly hexo-renderer-pug hexo-renderer-stylus --save
```

安装完成后，修改根目录的 `_config.yml`：

```yaml
theme: butterfly
language: zh-CN
```

然后清理并重启预览：

```powershell
hexo clean
hexo server
```

页面变成 Butterfly 风格，说明主题生效。

> 注意：这里是通过 npm 安装主题，主题实际位于 `node_modules/hexo-theme-butterfly`，不是传统的 `themes/butterfly` 目录。这种方式同样可以正常工作。

## 五、配置站点信息

编辑博客根目录的 `_config.yml`。

### 站点基础信息

```yaml
title: Cheng's Blog
subtitle: 记录学习与生活
description: Cheng Yang 的个人博客
author: YCheng
language: zh-CN
timezone: Asia/Shanghai
```

### 网址配置

```yaml
url: https://yc0203.github.io/yc0203/
root: /yc0203/
```

> 如果你的 GitHub 仓库名是 `用户名.github.io`，那么网址是：
> ```text
> https://用户名.github.io
> ```
> 如果仓库名是普通名字，比如 `yc0203`，那么网址要带仓库路径：
> ```text
> https://yc0203.github.io/yc0203/
> ```

## 六、配置 GitHub 部署

### 1. 安装部署插件

```powershell
npm install hexo-deployer-git --save
```

### 2. 修改部署配置

在 `_config.yml` 最底部：

```yaml
deploy:
  type: git
  repo: https://github.com/yc0203/yc0203.git
  branch: gh-pages
  message: Site updated: {{ now('YYYY-MM-DD HH:mm:ss') }}
```

### 3. 创建 GitHub 仓库

在 GitHub 上创建一个仓库，例如：

```text
yc0203
```

仓库建议设置为 Public。

### 4. 生成并部署

```powershell
hexo clean
hexo generate
hexo deploy
```

`hexo deploy` 会把 `public` 文件夹里的静态网页推送到 `gh-pages` 分支。

### 5. 开启 GitHub Pages

进入 GitHub 仓库：

```text
Settings -> Pages
```

选择：

```text
Branch: gh-pages
Folder: / (root)
```

保存后等待构建完成。

访问：

```text
https://yc0203.github.io/yc0203/
```

## 七、常用命令

| 简写 | 完整命令 | 作用 |
|---|---|---|
| `hexo s` | `hexo server` | 本地预览 |
| `hexo g` | `hexo generate` | 生成静态网页 |
| `hexo d` | `hexo deploy` | 部署到 GitHub |

| `hexo clean` | `hexo clean` | 清理缓存 |
| `hexo version` | `hexo version` | 查看 Hexo 版本 |

## 八、后期如何发表新文章

### 1. 新建文章

```powershell
hexo new "文章标题"
```

会自动生成：

```text
source/_posts/文章标题.md
```

### 2. 编写文章

打开生成的 Markdown 文件，填写 Front Matter：

```markdown
---
title: 文章标题
date: 2026-09-01 12:00:00
tags:
  - 标签1
  - 标签2
categories:
  - 分类1
description: 文章摘要
cover: /img/cover.jpg
---

这里是正文。
```

### 3. 本地预览

```powershell
hexo clean
hexo server
```

打开：

```text
http://localhost:4000
```

### 4. 部署上线

```powershell
hexo clean
hexo generate
hexo deploy
```

等待 GitHub Pages 构建完成后，文章就上线了。

### 5. 如果配置了 GitHub Actions

也可以直接推送源码：

```powershell
git add .
git commit -m "新增文章"
git push
```

GitHub Actions 会自动完成编译和部署。

## 十、常见问题

### 1. npm 安装超时

```powershell
npm config set registry https://registry.npmmirror.com
```

### 2. hexo deploy 提示没有 Git 插件

安装：

```powershell
npm install hexo-deployer-git --save
```

### 3. 页面没有应用 Butterfly

检查 `_config.yml`：

```yaml
theme: butterfly
```

然后：

```powershell
hexo clean
hexo generate
```

### 4. 本地能访问，线上打不开

检查 GitHub Pages 是否选择：

```text
gh-pages 分支
/ (root) 目录
```

### 5. 图片不显示

图片要放在：

```text
source/img/
```

然后引用：

```markdown
![](/img/图片.png)
```

如果博客部署在子目录，例如 `/yc0203/`，图片路径要写成：

```text
/yc0203/img/图片.png
```

## 十一、总结

搭建个人博客的核心流程并不复杂：

```text
Node.js + Git
    ↓
安装 Hexo
    ↓
安装 Butterfly
    ↓
配置站点和部署
    ↓
写文章
    ↓
hexo g && hexo d
    ↓
GitHub Pages 上线
```

以后写文章只需要记住：

```text
hexo new "标题"
写 Markdown
hexo clean && hexo generate && hexo deploy
```

博客就能持续更新了。
