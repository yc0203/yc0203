# 云产品入门全景指南：常用云产品详解

## 一、为什么要了解云产品

现在很多公司和个人开发者不再自己买物理服务器，而是直接使用云厂商提供的产品。

云产品可以理解为"把服务器、存储、数据库、网络、安全能力都做成可以随时租用的服务"。

这篇文章以腾讯云产品为主，介绍常用云产品是什么、有什么用、怎么用，以及主要性能参数。

## 二、产品快速分类表

| 分类 | 常用产品 | 一句话用途 |
|---|---|---|
| 计算 | CVM、Lighthouse、SCF | 提供 CPU、内存、运行环境 |
| 容器与中间件 | TKE、TCR、CKafka | 运行容器和消息队列 |
| 存储 | COS、CFS、CBS、CLS | 存文件、存日志、存数据库数据 |
| 数据库 | CDB MySQL、Redis、MongoDB | 存储结构化数据 |
| 网络 | VPC、CLB、EIP、NAT | 搭建云上网络 |
| CDN | CDN、GAAP | 加速访问 |
| 视频 | VOD、LVB、TRTC | 点播、直播、音视频通话 |
| 安全 | WAF、DDoS、CWP、KMS | 防护攻击和加密 |
| 大数据 | EMR、ClickHouse | 数据分析 |
| AI | 混元、ASR、人脸识别 | 智能能力 |
| 开发运维 | CM、CAM、DevOps | 监控、权限、自动化 |

## 三、计算类产品

### 1. 云服务器 CVM

#### 是什么

CVM 就是云上的虚拟机，你可以把它理解成一台随时可以创建的远程电脑。

#### 核心参数

- CPU：2核、4核、8核、16核等
- 内存：2GB、4GB、8GB、16GB、32GB等
- 系统盘：Linux / Windows
- 数据盘：云硬盘 CBS
- 带宽：按固定带宽或按流量计费
- 地域和可用区：影响网络延迟和数据位置

#### 怎么使用

1. 在腾讯云控制台购买 CVM
2. 选择操作系统，例如 Ubuntu / CentOS / Windows Server
3. 设置密码或密钥
4. 购买后通过 SSH 登录 Linux：
   ```bash
   ssh root@服务器IP
   ```
5. 部署 Nginx、Node.js、Java、数据库等

#### 用途

- 部署网站后端
- 运行爬虫
- 搭建数据库
- 跑自动化任务
- 做开发测试环境

---

### 2. 轻量应用服务器 Lighthouse

#### 是什么

Lighthouse 是简化版 CVM，面向个人开发者和小型项目，控制台更简单。

#### 核心参数

- 套餐制：固定 CPU、内存、流量、硬盘
- 预置镜像：WordPress、宝塔面板、Docker、Ubuntu 等

#### 怎么使用

1. 选择套餐
2. 选择应用镜像
3. 购买后直接在浏览器访问
4. 也可以通过 SSH 登录管理

#### 用途

- 个人博客
- 小型网站
- 测试环境
- 学习 Linux

---

### 3. 云函数 SCF

#### 是什么

SCF 是 Serverless 产品，不需要管理服务器，只需要上传代码，按调用次数计费。

#### 核心参数

- 运行内存：128MB 到 3GB 等
- 超时时间：通常最大几百秒
- 支持语言：Node.js、Python、Java、Go 等
- 触发方式：API 网关、定时触发、对象存储触发、消息队列触发

#### 怎么使用

1. 在 SCF 控制台创建函数
2. 编写或上传代码
3. 配置触发器
4. 调用 URL 或等待事件触发

#### 用途

- 定时任务
- 图片处理
- Webhook
- 轻量 API
- 自动化脚本

---

### 4. 弹性伸缩 AS

#### 是什么

AS 根据负载自动增加或减少 CVM 实例数量。

#### 核心参数

- 最小实例数
- 最大实例数
- 伸缩策略：CPU 使用率、内存、请求量
- 冷却时间

#### 怎么使用

1. 创建启动配置
2. 创建伸缩组
3. 绑定负载均衡 CLB
4. 设置伸缩策略

#### 用途

- 高并发时自动扩容
- 低峰时自动缩容
- 节省成本
- 保证服务稳定

---

### 5. 不常用但存在的计算产品

以下产品偏向企业级或特定场景，一般个人开发者用不到：

- 批量计算：适合大规模离线计算任务
- 高性能计算集群 HPC：适合科学计算、仿真
- 专用宿主机 CDH：独享物理服务器
- 黑石物理服务器：提供物理裸机服务器

个人学习建议优先掌握 CVM、Lighthouse、SCF。

## 四、容器与中间件

### 1. 容器服务 TKE

#### 是什么

TKE 是 Kubernetes 容器集群服务，帮你管理 Docker 容器。

#### 核心参数

- Master 节点：由云厂商托管或自管
- Node 节点：CVM 组成
- Pod 数量、CPU、内存
- 支持弹性伸缩

#### 怎么使用

1. 创建 TKE 集群
2. 配置 Node 节点
3. 编写 Deployment / Service YAML
4. 使用 `kubectl` 部署应用

#### 用途

- 微服务部署
- 容器化应用
- CI/CD 发布
- 高可用应用

---

### 2. Serverless 容器服务 EKS

#### 是什么

EKS 是不需要管理节点的 Kubernetes 服务，按 Pod 资源计费。

#### 核心参数

- 无需维护 Node
- 按 Pod 的 CPU/内存计费
- 秒级扩容

#### 用途

- 突发任务
- 短期批量任务
- 不想管理服务器的容器场景

---

### 3. 容器镜像服务 TCR

#### 是什么

TCR 是存放 Docker 镜像的私有仓库。

#### 怎么使用

```bash
# 登录镜像仓库
docker login ccr.ccs.tencentyun.com

# 打标签
docker tag myapp ccr.ccs.tencentyun.com/命名空间/myapp:latest

# 推送
docker push ccr.ccs.tencentyun.com/命名空间/myapp:latest
```

#### 用途

- 保存私有 Docker 镜像
- 配合 TKE 拉取镜像
- 版本管理

---

### 4. 消息队列 CKafka

#### 是什么

CKafka 是云上的 Kafka 消息队列，用于处理高吞吐消息。

#### 核心参数

- Topic 数量
- 分区数
- 消息保留时间
- 生产/消费吞吐量

#### 用途

- 日志收集
- 异步解耦
- 数据管道
- 流式处理

---

### 5. 消息队列 RocketMQ / RabbitMQ / Pulsar / MQTT / CMQ

这些消息队列适合不同场景：

| 产品 | 特点 | 适用场景 |
|---|---|---|
| RocketMQ | 功能丰富、事务消息 | 电商订单、交易系统 |
| RabbitMQ | 轻量、路由灵活 | 中小型系统 |
| Pulsar | 多租户、云原生 | 大规模消息系统 |
| MQTT | 轻量物联网协议 | 智能设备通信 |
| CMQ | 腾讯云老牌消息队列 | 简单异步任务 |

#### 使用方式

大部分消息队列使用方式类似：

1. 创建实例
2. 创建 Topic / Queue
3. 获取连接地址、账号密码
4. 在代码中使用 SDK 生产/消费消息

---

### 6. 云原生微服务平台 TSF

#### 是什么

TSF 是微服务管理平台，提供服务注册、配置管理、网关、监控。

#### 用途

- 微服务治理
- 服务发现
- 配置中心
- 链路追踪

> TSF 更适合中大型微服务项目，小型项目可以先不用。

## 五、存储类产品

### 1. 对象存储 COS

#### 是什么

COS 是云上的"文件大海"，可以存图片、视频、压缩包、静态网站文件。

#### 核心参数

- 存储容量：无限扩展
- 存储类型：标准存储、低频存储、归档存储
- 访问方式：HTTP/HTTPS URL
- 权限：公有读、私有读写

#### 怎么使用

```bash
# 使用 coscmd 上传文件
coscmd config -a 密钥ID -s 密钥KEY -b 存储桶名称 -r ap-guangzhou
coscmd upload local.jpg cos://bucket/local.jpg
```

#### 用途

- 存博客图片
- 存视频
- 静态网站托管
- 备份文件

---

### 2. 文件存储 CFS

#### 是什么

CFS 是云上的共享文件系统，多台 CVM 可以同时挂载访问。

#### 核心参数

- 容量：自动扩展
- 协议：NFS / CIFS
- 挂载点

#### 怎么使用

在 CVM 上挂载：

```bash
mount -t nfs 挂载点 /mnt/cfs
```

#### 用途

- 多台服务器共享文件
- 日志目录共享
- 大数据计算共享数据

---

### 3. 云硬盘 CBS

#### 是什么

CBS 是 CVM 的块存储设备，类似电脑里的硬盘。

#### 核心参数

- 容量：GB 到 TB
- 性能：普通云硬盘、SSD、高性能 SSD
- IOPS / 吞吐量

#### 用途

- CVM 系统盘
- 数据库数据盘
- 大数据存储

---

### 4. 日志服务 CLS

#### 是什么

CLS 是日志采集、检索、分析平台。

#### 核心参数

- 日志集、日志主题
- 采集方式：API、LogListener
- 检索语法

#### 怎么使用

1. 创建日志主题
2. 安装 LogListener
3. 配置采集路径
4. 在控制台检索日志

#### 用途

- 查看程序报错
- 分析访问日志
- 监控异常

---

### 5. 数据万象 CI

#### 是什么

CI 是图片和视频处理服务，可以自动压缩图片、加水印、转格式。

#### 怎么使用

通过 COS 触发或 API 调用：

```text
https://bucket.cos.ap-guangzhou.myqcloud.com/image.jpg?imageMogr2/thumbnail/300x300
```

#### 用途

- 图片压缩
- 图片裁剪
- 水印
- WebP 转换

---

### 6. 其他存储产品

以下产品偏向企业场景：

- 云 HDFS：大数据 Hadoop 文件系统
- 存储网关 CSG：把本地存储接入云
- 智能媒资托管：视频图片素材管理

一般个人开发者重点掌握 COS、CBS、CFS、CLS 就够用了。

## 六、数据库类产品

### 1. 云数据库 MySQL CDB

#### 是什么

CDB 是腾讯云托管的 MySQL，不需要自己安装和维护数据库。

#### 核心参数

- 版本：MySQL 5.7 / 8.0
- CPU/内存规格
- 存储空间
- 最大连接数
- 自动备份周期

#### 怎么使用

1. 创建 MySQL 实例
2. 设置账号密码
3. 获取内网/外网地址
4. 使用 Navicat、命令行或代码连接

```bash
mysql -h 数据库地址 -P 3306 -u root -p
```

#### 用途

- 网站数据存储
- 用户表、订单表
- 业务系统数据库

---

### 2. 云数据库 Redis

#### 是什么

Redis 是内存数据库，常用来做缓存。

#### 核心参数

- 内存容量：1GB、4GB、8GB 等
- 版本：Redis 5.0 / 6.0 / 7.0
- 最大连接数
- 持久化策略

#### 怎么使用

```bash
redis-cli -h 地址 -p 6379 -a 密码
```

#### 用途

- 缓存热点数据
- 分布式锁
- 排行榜
- Session 共享

---

### 3. 云数据库 MongoDB

#### 是什么

MongoDB 是文档型 NoSQL 数据库，适合灵活结构的数据。

#### 用途

- 爬虫数据
- 日志数据
- 商品信息
- 非结构化业务数据

---

### 4. 其他关系型数据库

| 产品 | 适用场景 |
|---|---|
| 云数据库 MariaDB | MySQL 兼容的开源数据库 |
| 云数据库 SQL Server | Windows/.NET 项目 |
| 云数据库 PostgreSQL | 复杂查询、地理数据 |
| TDSQL-C | 云原生 MySQL/PostgreSQL |
| TDSQL MySQL版 | 分布式数据库、大数据量 |

---

### 5. 其他 NoSQL / 工具

| 产品 | 用途 |
|---|---|
| 云数据库 Memcached | 简单缓存 |
| 时序数据库 CTSDB | 监控指标、IoT 数据 |
| 图数据库 TGraph | 社交关系、知识图谱 |
| 数据传输服务 DTS | 数据库迁移和同步 |
| 数据库智能管家 DBbrain | 数据库诊断优化 |
| 轻量数据库 LighthouseDB | 轻量 MySQL，适合个人项目 |

---

## 七、网络类产品

### 1. 私有网络 VPC

#### 是什么

VPC 是你在云上独立网络空间，可以自定义 IP 网段。

#### 核心参数

- CIDR 网段，例如 10.0.0.0/16
- 子网
- 路由表
- 网关

#### 怎么使用

1. 创建 VPC
2. 创建子网
3. 创建路由表
4. 把 CVM 放入子网

#### 用途

- 隔离云资源
- 搭建安全内网
- 配合数据库内网访问

---

### 2. 弹性公网 EIP

#### 是什么

EIP 是可以绑定到云服务器的公网 IP。

#### 特点

- 可以绑定/解绑
- 灵活更换资源
- 按带宽或流量计费

#### 用途

- 对外提供网站服务
- SSH 登录
- API 对外访问

---

### 3. 负载均衡 CLB

#### 是什么

CLB 把流量分发到多台 CVM 上。

#### 核心参数

- 监听协议：HTTP/HTTPS/TCP/UDP
- 后端服务器
- 健康检查
- 会话保持

#### 怎么使用

1. 创建 CLB
2. 添加监听器
3. 绑定多台 CVM
4. 配置健康检查

#### 用途

- 网站高可用
- 多台服务器分摊流量
- 弹性伸缩配合

---

### 4. NAT 网关

#### 是什么

NAT 网关让私有网络中的服务器访问公网，但不直接暴露公网 IP。

#### 用途

- 内网服务器下载软件
- 访问外部 API
- 保护内网资源

---

### 5. 云联网 CCN / 专线 / VPN / 安全组 / 网络 ACL

| 产品 | 用途 |
|---|---|
| 云联网 CCN | 多个 VPC 互通 |
| 专线接入 | 企业私有线路连接云 |
| VPN 连接 | 加密远程连接 |
| 安全组 | 服务器级别防火墙 |
| 网络 ACL | 子网级别防火墙 |

个人开发最常用的是：

- VPC
- 安全组
- CLB
- EIP

---

## 八、CDN 与加速

### 1. CDN

#### 是什么

CDN 把静态资源缓存到离用户近的节点。

#### 核心参数

- 加速域名
- 源站
- 缓存规则
- HTTPS 证书

#### 怎么使用

1. 添加加速域名
2. 配置源站
3. 添加 CNAME 解析
4. 等待生效

#### 用途

- 加速图片、CSS、JS
- 加速视频文件
- 降低源站压力

---

### 2. 全球应用加速 GAAP

#### 是什么

GAAP 是给跨国业务做网络加速的产品。

#### 用途

- 海外访问国内服务
- 国内访问海外服务
- 游戏加速

---

### 3. 边缘计算 / QUIC

- 边缘计算：把计算放到靠近用户的地方
- QUIC：基于 UDP 的新一代 HTTP 加速协议

一般个人项目使用 CDN 就足够了。

## 十、安全类产品

### 1. Web 应用防火墙 WAF

#### 是什么

WAF 保护网站免受 SQL 注入、XSS、CC 攻击。

#### 怎么使用

1. 添加域名
2. 把 DNS 解析切到 WAF
3. 开启防护规则

#### 用途

- 保护 Web 应用
- 过滤恶意请求

---

### 2. DDoS 防护

#### 是什么

DDoS 防护帮助抵御大流量攻击。

#### 用途

- 防流量洪水
- 防 CC 攻击
- 保证业务可用

---

### 3. 主机安全 CWP

#### 是什么

CWP 是服务器安全产品，检测木马、漏洞、异常登录。

#### 怎么使用

1. 在 CVM 安装云镜 Agent
2. 控制台查看风险
3. 修复漏洞

#### 用途

- 防暴力破解
- 检测 Webshell
- 安全基线

---

### 4. 密钥管理系统 KMS

#### 是什么

KMS 用于管理加密密钥。

#### 用途

- 数据库加密
- 文件加密
- API 密钥保护

---

## 十二、人工智能与机器学习

### 1. 腾讯混元大模型

#### 是什么

混元是腾讯的大语言模型。

#### 怎么使用

## 十四、怎么选择云产品

个人开发者推荐先掌握：

| 场景 | 推荐产品 |
|---|---|
| 建博客/小网站 | Lighthouse 或 CVM |
| 存图片/文件 | COS |
| 网站数据库 | CDB MySQL |
| 缓存 | Redis |
| 多台服务器分流 | CLB |
| 跑定时任务 | SCF |
| 容器化部署 | TKE |
| 防止攻击 | WAF + DDoS |
| 监控告警 | CM |

学习路径：

```text
CVM → COS → CDB → Redis → CLB → SCF → TKE
```

先学会最常用的，再逐步扩展。
