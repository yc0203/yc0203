## 二、1.1 数值分析的对象与任务

### 1. 对象

数值分析是研究用计算机求解数学问题的数值方法。

它研究的是：

- 如何把数学问题转化为计算机可计算的算法
- 如何保证计算结果足够准确
- 如何提高计算效率

### 2. 常见问题类型

- 非线性方程求根
- 线性方程组求解
- 插值与拟合
- 数值积分与数值微分
- 常微分方程初值问题
- 矩阵特征值问题

### 3. 数值分析的任务

```text
构造算法
    ↓
分析误差
    ↓
讨论收敛性
    ↓
分析数值稳定性
    ↓
估计计算复杂度
```

### 4. 核心思想

| 思想 | 说明 |
|---|---|
| 近似代替 | 用有限过程近似无限过程 |
| 离散化 | 把连续问题变成离散问题 |
| 递推化 | 用递推公式减少计算量 |
| 迭代化 | 用迭代逼近精确解 |

## 三、1.2 误差基础知识

### 1. 误差来源

#### ① 模型误差

实际问题抽象成数学模型时产生的误差。

例如：

```text
忽略空气阻力、摩擦力等次要因素。
```

#### ② 观测误差

测量工具和人为因素导致的数据误差。

#### ③ 截断误差 / 方法误差

用近似方法代替精确方法产生的误差。

例如：

```text
用泰勒展开前几项代替无穷级数。
```

#### ④ 舍入误差

计算机浮点数位数有限，保存数据时产生的误差。

例如：

```text
0.1 在二进制中不能精确表示。
```

### 2. 误差度量

#### ① 绝对误差

设精确值为 x，近似值为 x*，则绝对误差定义为：

```text
e = x - x*
```

如果存在正数 ε，使得：

```text
|x - x*| <= ε
```

则称 ε 为绝对误差限。

#### ② 相对误差

相对误差定义为：

```text
er = e / x
```

近似相对误差常用：

```text
er = e / x*
```

如果存在正数 εr，使得：

```text
|e / x| <= εr
```

则称 εr 为相对误差限。

#### ③ 有效数字

如果近似值 x* 的绝对误差不超过某一位的半个单位，则从该位起直到 x* 的第一位非零数字为止的所有数字都叫有效数字。

简单判断方法：

```text
误差限 <= 0.5 × 10^(m-n)
```

其中：

- m：小数点前第一位非零数字所在位数
- n：有效数字位数

例如：

```text
π ≈ 3.1416
```

通常认为有 5 位有效数字。

#### ④ 误差度量易错点

- 绝对误差有量纲
- 相对误差无量纲
- 有效数字越多，绝对误差限越小
- 有效数字与小数点后位数不是一回事

### 3. 初值误差传播

#### ① 一元函数

设 y = f(x)，x 有误差 Δx，则 y 的误差近似为：

```text
Δy ≈ f'(x) Δx
```

相对误差传播：

```text
Δy / y ≈ [x f'(x) / f(x)] × (Δx / x)
```

#### ② 多元函数

设 y = f(x1, x2, ..., xn)，则：

```text
Δy ≈ |∂f/∂x1| Δx1 + |∂f/∂x2| Δx2 + ... + |∂f/∂xn| Δxn
```

#### ③ 条件数

条件数用于衡量问题对误差的敏感程度：

```text
条件数 ≈ |x f'(x) / f(x)|
```

- 条件数小：问题良态，误差放大不严重
- 条件数大：问题病态，微小输入误差可能引起很大输出误差

#### ④ 典型例子

计算：

```text
f(x) = x1 - x2
```

当 x1 和 x2 非常接近时，减法会产生严重的相对误差放大，称为"灾难性抵消"。

避免方法：

```text
通过公式变形避免两个接近的数相减。
```

## 四、1.3 舍入误差分析及数值稳定性

### 1. 浮点数系

计算机中实数通常用浮点数表示：

```text
x = ± 0.d1d2...dt × β^e
```

其中：

- β：基数，通常为 2
- t：尾数字长
- e：指数
- d1 非零

### 2. 机器精度

机器精度是浮点数系中最重要的参数之一。

常用表示：

```text
eps = 0.5 × β^(1-t)
```

它的含义是：1 与大于 1 的最小浮点数之间的距离的一半。

机器精度越小，浮点数表示越精确。

### 3. 浮点运算的舍入误差

计算机进行加减乘除后，结果需要重新舍入到浮点数系中。

设 x、y 是浮点数，则：

```text
fl(x op y) = (x op y)(1 + δ)
```

其中：

```text
|δ| <= eps
```

也就是说，每次浮点运算都可能引入一个很小的相对误差。

### 4. 舍入误差累积

单次舍入误差很小，但大量运算后误差可能累积放大。

影响因素：

- 运算次数
- 算法结构
- 问题本身的条件数

### 5. 算法的数值稳定性

#### 定义

一个算法如果对初始误差和舍入误差不敏感，计算结果能保持可靠，则称该算法是数值稳定的。

如果误差在计算过程中被不断放大，则称算法不稳定。

#### 稳定算法与不稳定算法

```text
稳定算法：误差增长缓慢，结果可靠
不稳定算法：误差指数增长，结果失真
```

#### 经典考点例子

计算积分：

```text
In = ∫₀¹ x^n / (x+5) dx
```

如果使用递推公式：

```text
In = 1/n - 5 I(n-1)
```

向前递推可能不稳定，误差会被放大。

如果改用向后递推，可能更稳定。

#### 判断方法

- 看误差是否被放大
- 看误差增长是线性还是指数
- 看是否出现两个接近数相减
- 看是否除以很小的数

### 6. 避免不稳定的常用技巧

- 避免两个相近数相减
- 避免除以绝对值很小的数
- 减少运算次数
- 使用稳定的递推方向
- 使用高精度数据类型
- 对公式做等价变形

## 五、主要考点总结

### 1. 必背概念

| 概念 | 关键点 |
|---|---|
| 截断误差 | 方法本身近似引起 |
| 舍入误差 | 浮点数存储和运算引起 |
| 绝对误差 | e = x - x* |
| 相对误差 | er = e / x |
| 有效数字 | 与绝对误差限有关 |
| 条件数 | 衡量问题敏感性 |
| 机器精度 | 浮点数表示精度 |
| 数值稳定性 | 误差是否被放大 |

### 2. 常考题型

- 判断误差类型
- 计算绝对误差限和相对误差限
- 判断有效数字位数
- 分析误差传播
- 判断算法是否稳定
- 给出避免误差扩大的算法改进

### 3. 高频考点

- 用泰勒展开说明截断误差
- 浮点数舍入误差估计
- 递推公式稳定性判断
- 相近数相减的危害
- 条件数与病态问题

---

## 六、易错提醒

1. 相对误差分母有时用 x，有时用 x*，题目中要看清。
2. 有效数字位数不是看小数点后有几位。
3. 截断误差和舍入误差不能混为一谈。
4. 算法稳定不等于结果绝对精确，只是误差不被严重放大。
5. 条件数大是问题本身病态，不是算法造成的。
6. 避免相近数相减，可以通过有理化、泰勒展开等方法改造公式。

## 八、本章重点一句话

数值分析就是用近似方法求解数学问题，同时研究误差如何产生、如何度量、如何传播，以及如何设计数值稳定的算法。
